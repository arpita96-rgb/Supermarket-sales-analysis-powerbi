# 📚 Data Dictionary – Supermarket Sales Analysis

## 1. Introduction

A Data Dictionary provides detailed information about the fields used in a dataset, including their names, descriptions, business meanings and data types.

This document describes the fields referenced in the Supermarket Sales Analysis Power BI report.

**Project:** Supermarket Sales Analysis  
**Tool:** Microsoft Power BI  
**Analysis Level:** Intermediate

---

## 2. Sales & Transaction Fields

| Column Name | Description | Expected Data Type |
|---|---|---|
| Order_Date | Date on which the order was placed | Date |
| Variation | Time variation or reporting period field | Verify in model |
| Branch | Supermarket branch identifier | Text |
| City | City where the transaction occurred | Text |
| Product | Name of the purchased product | Text |
| Category | Product category | Text |
| Quantity | Number of units purchased | Whole Number |
| Gross_Sales | Sales value before deductions | Decimal |
| Net_Sales | Sales value after deductions | Decimal |
| Discount | Discount applied to the transaction | Decimal |
| Payment_Method | Payment method used by the customer | Text |

---

## 3. Customer Fields

| Column Name | Description | Expected Data Type |
|---|---|---|
| Customer_ID | Unique customer identifier | Text |
| Gender | Customer gender category | Text |
| Membership_Type | Customer membership classification | Text |
| Customer_Rating | Customer rating associated with a product or transaction | Decimal |
